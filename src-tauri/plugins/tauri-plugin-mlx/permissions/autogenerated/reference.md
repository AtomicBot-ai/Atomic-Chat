## Default Permission

Default permissions for the MLX plugin

#### This default permission set includes the following:

- `allow-get-mlx-server-version`

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>

</td>
<td>

</td>
</tr>

<tr>
<td>

`mlx:deny-get-mlx-server-version`

</td>

</td>
</tr>
