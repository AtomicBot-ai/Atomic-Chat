# 2026-10-03 — Choose TensorRT-LLM models in the Model Hub, as its third format

- **Context:** TensorRT-LLM models could be found and downloaded only on the provider page (`TensorrtLlmModelPicker`: the descriptor's curated list and an `owner/repo` field, no search, no README, no cancel, its own progress bar). The Model Hub knew GGUF and MLX and only pointed at that page (`TensorrtLlmHubHint`). The provider's visibility is the core's answer, with no platform check in the app (2026-10-01, "Ship TensorRT-LLM on Linux and Windows and let the core hide it"); the Hub's long tail is Hugging Face's own listing under the picks (2026-09-15, "List the rest of Hugging Face under the picks").
- **Decision:** TensorRT-LLM is a value of the Hub's format filter next to GGUF and MLX, and the Hub is the only place a TensorRT-LLM model is chosen and downloaded. The format is offered exactly where the provider is shown and the core's plan has no `compute-capability-too-low` blocker — no OS check of the Hub's own; other blockers replace the list with the plan's reasons. Under it the Hub lists the descriptor's curated models that the core's check passes on some card, then Hugging Face's `filter=safetensors` listing with `expand[]=config,safetensors`, narrowed in the app only by `config.architectures` against the descriptor's `supported_architectures` and by an estimate of the weights (parameters × dtype width) against the largest card. The quantization format is never read in the app: whether a model runs is the core's verdict in its card, and a repository typed as `owner/repo` skips the narrowing. Downloads run through the shared download panel under one id, with cancel and no pause. The provider page keeps settings, logs and installed models, and opens the Hub with `?engine=tensorrt-llm`.
- **Consequences:** One code path for choosing a model, and the picker and the Hub hint are gone. The feed may show models the core then refuses (a quantization this card cannot run, a false `ok` for Nemotron-H with dense MLPs is the core's debt), and may hide one whose repository carries duplicate weights (`original/`) — exact `owner/repo` is the way around. An installation stays bound to its descriptor, so an old engine sees its old curated list and architectures. A card with shared memory (no VRAM figure) disables the size estimate. The Hub's `engine` search parameter now works for GGUF and MLX as well.
